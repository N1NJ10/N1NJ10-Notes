## Questions And Feedback

Use the **Issues** tab for anything related to the notes vault or the material in this repository:

- **Question:** Something in a note or playbook is unclear, or you want more depth on a topic.
- **Correction:** A typo, broken link, formatting problem, or factual mistake.
- **Request:** A missing section, a new topic, or a playbook/mind map you would like to see.
- **General feedback:** Thoughts on a note or on the overall structure.

### How To Submit

1. Open the **Issues** tab.
2. Click **New issue**.
3. Pick the template that matches your request.
4. Fill in the details, including the note link (or file path) when possible.
5. Submit the issue.

See [CONTRIBUTING.md](./CONTRIBUTING.md) before opening an issue.
